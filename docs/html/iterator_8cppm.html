Detailed Description

Iterator vocabulary for the container + algorithm library: the category tag hierarchy, the concepts that constrain algorithms (e.g. sort needs random access), IteratorTraits (raw T* is the contiguous iterator everywhere here), ReverseIterator, and the distance/advance/next/prev free functions.

Note
Lives in worse::core (the parent namespace), NOT worse::core::container, so the vocabulary is visible unqualified from both worse::core::container::* and worse::core::algorithm::* — the same rationale as type_traits/utility.
