Detailed Description

◆ IsAlwaysEqual

using worse::core::container::Allocator::IsAlwaysEqual = std::true_type

Policy advertised to AllocatorTraits: the allocator is always-equal.

Note
All instances compare equal (operator== below always returns true), so containers may steal storage on move-assignment and swap pointers unconditionally, and those operations are noexcept.

Allocate sizeBytes at alignment, threading the debug name + source location into an AllocInfo.

Returns
Pointer to the storage, or nullptr on OOM.
Note
WE_FORCEINLINE so the AllocInfo/source_location tracking provably DCEs to a bare operator new on the hot path (memory::allocate ignores allocInfo in this build). Without it the optimizer leaves Allocator::allocate out-of-line, pinning the tracking + a call frame on every node push/free (~9% vs a thin ::operator new allocator) (R43).
