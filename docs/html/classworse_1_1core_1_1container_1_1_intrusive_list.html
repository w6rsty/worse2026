Detailed Description

template<typename T>
class worse::core::container::IntrusiveList< T >

Intrusive doubly-linked list over an embedded circular sentinel with O(1) size.

Template Parameters
Telement type; must derive publicly from IntrusiveListNode.
Note
Allocates and owns nothing – the link pointers live in the element, so link/unlink is O(1) pointer surgery with zero heap traffic. Move-only; never constructs or destroys elements. See the file-level docs for the full contract.
