Detailed Description

Typed, force-inlined wrappers over the raw compiler intrinsics the container and algorithm code relies on, so call-sites read intent (intrinsics::memCopy(...)) instead of a bare __builtin_*.

Note
Follows the existing addressOf wrapper precedent (iterator.cppm). The mem* wrappers take void*/void const* so the call-site static_cast<void*> casts that silence -Wnontrivial-memcall on trivially-RELOCATABLE-but-not-copyable types keep working unchanged.
WE_FORCEINLINE guarantees these collapse to the underlying builtin with zero codegen change on the hot paths (the force-inline that R42/R47 proved load-bearing for push/insert).
Deliberately NOT wrapped: addressOf (already wrapped, iterator.cppm), __STDCPP_DEFAULT_NEW_ALIGNMENT__ (a std macro, memory.cppm), and __builtin_unreachable (lives in macro.hpp, a header that cannot import a module).
