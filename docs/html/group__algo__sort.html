Parameters

Trivially-copyable element types partition with a branchless Lomuto scheme (no data-dependent branch in the hot scan, so random inputs pay no misprediction penalty); other types use Hoare partitioning. (R44)

Stable in-place sort of [first, last) by comp (preserves order of equal elements).

Parameters
firstiterator to the first element of the range.
lastiterator one past the last element of the range.
Template Parameters
RandomItrandom-access iterator.
Parameters
compstrict-weak-ordering comparator (default Less<> => ascending).
Note
Buffered O(n log n) merge when an (n+1)/2 allocator scratch is available (std::stable_sort speed); falls back to the alloc-free in-place rotation merge (O(n log^2 n), R36, constexpr-usable) during constant evaluation or on allocation failure. Use sort when stability is not needed (introsort, no allocation). (R41)
