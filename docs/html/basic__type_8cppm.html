Detailed Description

Fixed-width scalar aliases (u8/i32/f32/usize/...), their numeric limits, and the matching _u8/_i32/_f32/... user-defined literals.

Variable Documentation

◆ F32_MIN

f32 worse::F32_MIN = std::numeric_limits<f32>::min()
constexpr

F32_MIN is the smallest positive normalized value; F32_LOWEST is the most negative finite value.

Note
F32_EPSILON is the machine epsilon (1 ulp at 1.0) — distinct from math::EPSILON, which is a comparison tolerance.
