Detailed Description

template<typename T, usize N>
struct worse::core::container::StaticArray< T, N >

Fixed-size inline array (the engine's std::array): N elements stored directly, no allocator, no heap, fully constexpr.

Aggregate (public data member, no user-declared ctors) so aggregate initialization works: StaticArray<int, 3> a{1, 2, 3}; sizeof(StaticArray<T, N>) == sizeof(T[N]) (no overhead).

Note
Bounds checked by a debug-only WE_ASSERT (release: UB, matching the engine's no-throw contract).
