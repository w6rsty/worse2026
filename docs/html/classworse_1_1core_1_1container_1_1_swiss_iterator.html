Detailed Description

template<typename Value, bool IsConst>
class worse::core::container::SwissIterator< Value, IsConst >

Forward iterator over the full (occupied) slots of a SwissTable.

Note
Advances by index, skipping empty/deleted control bytes up to the capacity bound (no sentinel); end() is the iterator at index == capacity.
