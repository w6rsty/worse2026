Detailed Description

template<typename Value, typename Key, typename KeyOfValue, typename Hasher, typename KeyEqual, typename Allocator = WE_DEFAULT_ALLOCATOR>
class worse::core::container::HashTable< Value, Key, KeyOfValue, Hasher, KeyEqual, Allocator >

Open-addressing hash table using Robin Hood hashing with a u16 DIB and backward-shift deletion.

Template Parameters
Valuestored element type.
Keykey the element is looked up by.
KeyOfValueextractor mapping a stored Value to its Key (identity for a set, .first for a map).
Hasherhash functor for Key.
KeyEqualequality comparator for Key.
Allocatorallocator type.
Note
Iteration order is unspecified and changes on rehash. Any rehash or erase invalidates all iterators and references (R8/R9).
