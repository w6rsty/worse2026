Detailed Description

template<typename Value, typename Allocator>
class worse::core::container::HashTableBase< Value, Allocator >

Storage + RAII half of HashTable (non-exported): owns the two raw buffers and the allocator (EBO).

Note
Its destructor frees the BUFFERS only – destroying the live elements is the derived HashTable's job (it runs its destructor first), mirroring ArrayBase.
