Template Parameters
Telement value type.
ValueTT or T const — carries the iterator's const-ness.
Note
The node pointer is stored non-const (traversal never mutates a node, and a const list still yields valid node addresses). Dereference downcasts the base-node pointer to the value-carrying node — valid for every real node; the anchor must never be dereferenced.
