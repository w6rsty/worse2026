Telement value type.
ValueTT or T const — carries the iterator's const-ness.
Note
The node pointer is always stored non-const (traversal never mutates a node, and a const list still yields valid node addresses). Dereference downcasts the node back to the element via static_cast – valid since T derives from the node.
