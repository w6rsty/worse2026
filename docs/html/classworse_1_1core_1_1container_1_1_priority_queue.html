Detailed Description

template<typename T, typename Container = Array<T>, typename Compare = Less<>>
class worse::core::container::PriorityQueue< T, Container, Compare >

Container ADAPTER keeping an underlying random-access sequence (default Array<T>) arranged as a binary heap, so the highest-priority element is always at the front.

The default comparator Less<> makes a MAX-heap – top() is the largest element – matching std::priority_queue (pass Greater<> for a min-heap).

Note
All heap maintenance routes through the algorithm layer (makeHeap/pushHeap/ popHeap): push appends then sifts the newcomer up; pop swaps the root to the back, re-sifts, then drops the back.
The adapter owns nothing the container does not – it is just policy over a sequence – so it inherits the container's allocator and relocation behaviour for free.
