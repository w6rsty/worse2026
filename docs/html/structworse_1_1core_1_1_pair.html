struct worse::core::Pair< T1, T2 >

A two-element aggregate-like value type with public first/second.

Note
Public members (R2) keep STL muscle-memory and enable structured bindings (auto [a, b] = pair;). Comparison is == (member-wise) and < (lexicographic); C++20 synthesizes != from ==.
