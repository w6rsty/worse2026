Detailed Description

template<typename Value, typename Key, typename KeyOfValue, typename Compare = Less<Key>, typename Allocator = WE_DEFAULT_ALLOCATOR>
class worse::core::container::RBTree< Value, Key, KeyOfValue, Compare, Allocator >

Ordered unique associative engine over a red-black tree; backs Set and Map.

Template Parameters
Valuethe stored value type (the key itself for Set, Pair<Key, T> for Map).
Keythe key type used for ordering and lookup.
KeyOfValuefunctor extracting the Key from a Value (identity for Set, .first for Map) – mirrors hash_table.
Comparestrict-weak-ordering key comparator.
Allocatornode allocator.
Note
O(log n) insert/erase/find, sorted in-order iteration, stable element addresses.

inline

Single-descent find-or-insert: locate key, inserting via factory if absent.

If present returns {it, false}; else constructs the value via factory() at the located slot and returns {it, true}.

Template Parameters
Kquery type for the descent.
Factorynullary callable producing the Value to insert.
Parameters
keythe key to locate.
factoryinvoked ONLY on the insert branch.
Precondition
factory() must return a Value whose key compares equal to key.
Note
ONE O(log n) walk instead of find()+insert()'s two; backs Map::operator[]/tryEmplace/insertOrAssign (R45). Mirrors insertUniqueImpl's descent but keyed on key.
