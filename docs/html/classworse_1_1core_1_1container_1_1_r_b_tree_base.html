template<typename T, typename Allocator>
class worse::core::container::RBTreeBase< T, Allocator >

Storage + RAII half of the tree: owns the allocator, embedded header, and size.

Provides the node allocate/construct/free + recursive clear primitives.

Note
The BASE destructor frees ALL nodes (R25).
