Detailed Description

template<typename Value, typename Info, bool IsConst>
class worse::core::container::HashTableIterator< Value, Info, IsConst >

Forward iterator over the occupied slots of a HashTable.

Note
Wraps a slot cursor + a parallel info cursor; operator++ skips empty slots, stopping at the guard sentinel (a non-zero info byte one past the table) so end() needs no separate bounds check. Exposes the five nested typedefs so IteratorTraits / the iterator concepts recognise it.
