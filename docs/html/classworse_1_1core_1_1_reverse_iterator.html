Detailed Description

template<typename It>
class worse::core::ReverseIterator< It >

Adapts an iterator so traversal runs backwards.

Note
base() returns the wrapped iterator; dereference reads the element BEFORE base() (so rbegin = reverse(end) dereferences the last element). Random-access ops are provided and only instantiate when the underlying iterator supports them.
