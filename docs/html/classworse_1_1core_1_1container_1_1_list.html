Detailed Description

template<typename T, typename Allocator = WE_DEFAULT_ALLOCATOR>
class worse::core::container::List< T, Allocator >

Allocating doubly-linked list with an embedded circular sentinel and O(1) size.

Template Parameters
Telement type (must be non-const, non-volatile).
Allocatorallocator type; defaults to the engine default allocator.
Note
Game-perf shape (EASTL/Unreal-flavored, not a std clone): stable element addresses, O(1) splice/erase, cached O(1) size (R30), full allocation-free algorithm surface. See the file-level docs for the iterator-stability contract.

template<typename Compare>
requires CompareFor<Compare, T>
void worse::core::container::List< T, Allocator >::sort ( Compare comp)
inline

Stably sort the list using comp.

Template Parameters
Comparestrict-weak-ordering comparator over T.
Parameters
compcomparator defining the order.
Note
Allocation-free, stable, bottom-up binned merge sort. The ring is broken into a null-terminated singly-linked chain so the merges touch ONLY mpNext (one pointer write per node, vs ~6 for a full doubly-linked ring splice); a single O(n) pass then rebuilds mpPrev and re-circularizes. O(log n) stack bins, no allocation, no value copies; mSize invariant. Beats the SGI ring-splice list::sort by halving the pointer traffic in the inner merge.
