Detailed Description

template<typename T, typename Allocator = WE_DEFAULT_ALLOCATOR>
class worse::core::container::ForwardList< T, Allocator >

Allocating singly-linked list with an embedded head sentinel and O(1) size.

Template Parameters
Telement type (must be non-const, non-volatile).
Allocatorallocator type; defaults to the engine default allocator.
Note
Game-perf slist shape (EASTL/Unreal-flavored, not a std clone): the *After mutation API, cached O(1) size (R30), full allocation-free algorithm surface. See the file-level docs for the trade-offs and iterator-stability contract.
